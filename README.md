# AI Dev OS Trusted Skill Manifest Repository

This repository is the trusted skill manifest repository for AI Dev OS.

It stores only skill manifest metadata used to discover and verify available skills. It does not contain executable remote skill code, and AI Dev OS must not execute code directly from this repository.

The manifests in this repository describe skill names, versions, capabilities, declared entries, and required permissions so clients can make explicit trust and permission decisions before using any skill implementation.
